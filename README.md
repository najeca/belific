# Belific

A warm, focused productivity app for managing your daily schedule with Pomodoro timer.

## Features

- **📅 Daily Schedules** - Pre-loaded 14-day exam prep schedule
- **✏️ Edit & Delete Events** - Tap any event to edit or remove
- **📝 Notes** - Add notes to any event
- **⏱️ Pomodoro Timer** - Focus sessions with customizable durations
- **📆 Calendar View** - Navigate and view any day
- **📱 PWA** - Install on your phone's home screen

## Quick Start

1. Deploy to GitHub Pages
2. Open `https://YOUR_USERNAME.github.io/Belific/` on your phone
3. Add to Home Screen via Share menu

## Windows desktop app (Belific 2.x)

The newer Belific app for Windows lives in `desktop/` (see `desktop/README.md` for how to build and install it). It works fully without an account and stores your data on your computer.

**The Windows installer is not code signed**, so Windows SmartScreen may show "Windows protected your PC" when you run it. Choose **More info**, then **Run anyway**. There is no auto update: install a newer installer over the old one and your data is kept.

Privacy policy: https://najeca.github.io/belific/privacy.html

# Session 2026-10-06, checkpoint 4.4 (optional and short durations)

Version 2.8.4.

## What changed
- `lib/duration.ts`:
  - **Duration is optional.** The editor has an explicit **None** chip, the default for every new task (a captured thought never had a duration). It stores no `durationMinutes`.
  - The quick chips after None are 15m, 30m, 1h and 2h. Custom keeps Hours 0 to 24; Minutes are now 0 to 55 in 5 minute steps (`MINUTE_OPTIONS`).
  - `DURATION_STEP` and `MIN_DURATION` are now 5, and `joinDuration`, `clampDuration`, `splitDuration` and `isValidPick` follow. 24h only allows 0 minutes; every other minute option is disabled at 24.
  - New `isQuickDuration` decides whether Custom opens by itself (only for a stored value that is not a chip; None counts as a chip).
  - `formatDuration` already gave "10m" and "1h 5m". Stored values (15, 30, 60, 120, anything else) load and display unchanged, and nothing is rewritten unless a duration is picked.
- `lib/timebox.ts`: new `blockHeightPx(minutes)` (true scale, minimum `MIN_BLOCK_PX` = 20) and `isCompactBlock(heightPx)` (below `COMPACT_BLOCK_PX` = 36). Layout, the resize preview and the drop preview all use `blockHeightPx`.
- `TimeboxPane.tsx`: a compact task block shows one line, its title plus its true duration ("Short block 10m"). Taller task blocks show the start time and duration on the second line. Event blocks use the same compact rule.
- Unchanged:
  - Starts, moves and drops snap to 30 minutes.
  - Resize keeps 30 minute steps with a 30 minute minimum, so a 10m block dragged at its edge becomes 30. Shorter durations come only from the editor.
  - A task with no duration dropped on the Timebox gets `DEFAULT_TASK_MINUTES` (30).
  - A Day plus no duration sits in its kanban column with no duration chip.
- No time input was added anywhere, and no notifications.

## Choices where the brief was silent
1. The None chip is selected whenever no duration is stored, and choosing it removes `durationMinutes` from the task. Tapping a selected quick chip no longer clears it (None does that now).
2. With None, the Custom picker shows 0 h 30 min as a starting point but stores nothing until a select is changed; the text beside it reads "Not set".
3. An odd stored value such as 7 shows in the Custom selects as the nearest 5 minute option, and is only rewritten if the user changes a select.
4. The compact minimum stays at 20px. A 30 minute slot is 28px, so a block under 30 minutes is visibly shorter (19px measured, including its 1px gap) and does not look like it fills the slot. Times under about 21 minutes all draw at 20px; their label gives the true length.
5. A tall task block's second line changed from "09:30 task" to "09:30 1h" (and "done" when completed), so the true duration is visible on every block.
6. The full title of a compact block is not shown on hover (react-native-web Text has no tooltip). It truncates with an ellipsis and opens the editor on click.
7. Overlap layout still uses true minutes, so a 10 minute block followed by one starting 10 minutes later would overlap visually at 20px. Starts are only set by drag, which snaps to 30 minutes, so this does not occur in practice.

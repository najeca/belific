## Silent choices
- **Daily reminder is on by default** (the prompt gave a default time and an off toggle, which reads as on). It costs nothing when no task is planned without a time. Flip the default in `desktop/src/settings.js` if you would rather opt in.
- **Lead time:** the iOS app has none, so toasts fire at the start time.
- **Events notify only if they have a valid `HH:mm` start and a date inside 48 hours.** Every CustomEvent in storage is user created, so all of them count (template events are not stored as CustomEvents).
- **Events that the page sends are bounded to 72 hours, main applies the exact 48 hour window.** The extra day is slack for clocks.
- **Late toasts are dropped, not delayed:** more than 5 minutes late for events and tasks, more than 3 hours for the daily reminder. After sleep, due timers are fired or dropped on resume.
- **If the app is not running at 09:00 that day's reminder is skipped.** Nothing is queued for later.
- **Daily reminder body** is "1 task planned for today" or "n tasks planned for today", title "Belific", on the day itself (also when the 48 hour plan covers tomorrow's 09:00).
- **A hidden window ticks every 120 s** to sync and resend the payload (decision 013 item 5 only polls while visible). Not a sync rule change; recorded in decision 017.
- **First close note** is a quiet notification (not a dialog), shown once, remembered in settings.
- **Start with Windows** only writes the Windows startup entry from an installed (packaged) app, never from `npm run desktop` or a test; it starts hidden in the tray (`--hidden`) when close to tray is on.
- **File, Quit** now really quits (it sets the quitting flag), with Ctrl+Q.
- **`app.getName()` stays `belific-desktop`** so the installed app and `npm run desktop` share `%APPDATA%\belific-desktop`. The installer's product name is only in the builder config. No `productName` in package.json (that would move the data folder).
- **The installer registers `belific://`** (electron-builder `protocols`) and the app also calls `setAsDefaultProtocolClient` at launch.
- **Installer settings:** one click, per user, no elevation, shortcuts on, uninstall keeps app data. No signing, no publish, no auto update. About 110 MB (it contains Electron). The `build-web.js` exit uses `process.exitCode` because Node 26 on Windows intermittently hit a libuv assertion with `process.exit` after a child run.
- **`author` is "Belific"** in `desktop/package.json` (the file properties otherwise said GitHub, Inc.).
- **Test hooks:** only environment variables that skip machine wide writes (`BELIFIC_NO_PROTOCOL_REGISTER`, `BELIFIC_NO_LOGIN_ITEM`). The harness captures `Notification.prototype.show` and `Tray.prototype.setContextMenu` from outside, so the app has no capture code.

## Try it by hand
1. **Installer.** `cd desktop`, `npm run dist`, then double click `desktop\dist\Belific-Setup-2.11.0.exe`. SmartScreen: More info, Run anyway. Belific opens; your data is in `%APPDATA%\belific-desktop`.
2. **Tray.** Close the window with the X: a notification says Belific is still running (once), and a Belific icon is in the tray (maybe under the ^ arrow). Right click it: Open Belific, Quit Belific. Close again: no second note. Quit Belific ends the app (check Task Manager for no Belific).
3. **A toast.** Add an event on a day, or drag a task onto the Timebox, starting about 2 minutes from now. Close the window to the tray and wait. A Windows toast with the title appears at the start time. Click it: the window opens.
4. **Daily reminder.** Plan two tasks for today (the Day field, no time). Open the account line, Settings, set Remind me at to 2 minutes from now, close the window to the tray, and wait: one toast "2 tasks planned for today". Complete one task and set the time again: "1 task planned for today". Complete both: nothing fires.
5. **Start with Windows.** Settings, Window, turn it on, sign out of Windows and back in: Belific should be in the tray, window hidden. Turn it off again afterwards if you do not want it.
6. **Uninstall.** Settings, Apps, Belific, Uninstall; check the data folder is still there.

## Shipped
- **iOS 2.1.0** (per Jethro, live on the App Store): Today, Brain Dump and Calendar tabs; Tasks and Settings as pushed screens; local notifications; optional Sign in with Apple plus Supabase sync (7 tables).
- **Desktop (app version 2.12.0, checkpoints 0 to 7 plus the 2b and 2c corrections, the 6.1 sign in hardening and 8.2, editing on the card)**: an Electron shell in `desktop/` loads the Expo web export over `app://`, stores data as files in the main process with a daily backup (newest 14), and shows three real panes. **Brain Dump**: the thing you capture IS the task (Enter creates a Task); the pane lists incomplete tasks with no Day plus any legacy Brain Dump items (converted on first save), with a collapsed "Done today". **Week board**: forward-only, days only (no Unscheduled column); clicking a row or card opens the editor (name, duration, priority, label, notes, Day, Repeat). **Timebox** day grid (events plus placed tasks, faint half hour lines; **a task gets a time only by being dragged onto the Timebox**, there is no time input anywhere). **Drag and drop** (checkpoint 4, pointer events, decision 019): rows to days or Timebox slots, cards between days, cards and blocks back to the left pane, block move and resize in 30 minute steps, edge dwell week change, Escape cancels. **Label colours** (8 palette colours, tint plus edge on cards and blocks, a dot on rows; `colorKey` local only) and **optional durations** (None by default; 15m, 30m, 1h, 2h, or Custom in 5 minute steps up to 24h; short blocks drawn compact on the Timebox). **Repeat**: Weekly (1 to 7 days, all seven reads Daily), Every 2 weeks, Monthly on a day 1 to 31, with a plain summary line. **Labels**: ten one-tap suggestions, unique names, rename, and delete (a tombstone; tasks move to a same-named label or lose it). Signed out it is local only. **Sign in with Apple (checkpoint 6, code only until setup):** the footer line opens a small Settings modal (Account, Sync, Data); sign in goes through the system browser, the session is stored encrypted, a "pre-signin" backup is taken first. **Editing on the card (checkpoint 8.2, 2.12.0, decision 021):** there is no task editor modal any more; every card has its own controls and small dropdowns (label, priority, duration, repeat, reminder, move to day), an inline title rename, an in place expansion with notes and subtasks, a popover for placed Timebox blocks, a Filter button, per task reminders and drag onto a card as a subtask (see the nav spec). Hardened in 2.11.1 (stray links cannot cancel a sign in, a different account asks before uploading, session files are never backed up or exported, link allow list). It cannot work until Jethro completes `docs/APPLE_SIGNIN_SETUP.md`. **Notifications, tray and installer (checkpoint 7):** the main process schedules toasts for event starts and placed tasks (at their start time) and a grouped daily reminder of planned tasks with no time (decision 020, default 09:00); closing the window keeps the app in the system tray (Open, Quit), Start with Windows is opt in; Settings has Notifications and Window sections; `npm run dist` in `desktop/` builds an unsigned per user NSIS installer (see `desktop/README.md`). Desktop UI lives in `mobile/components/desktop/` behind `DesktopEntry.web.tsx`; none of it is in the iOS bundle. Run it with `npm run desktop` in `desktop/`. Decisions 010, 011, 015, 016 and 019 are proposed but built against.

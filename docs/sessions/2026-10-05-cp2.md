- `DesktopHome.tsx`: owns the modal state and the shared refresh counter.
- `mobile/package.json` gets `npm test`; `tsconfig.json` gets `allowImportingTsExtensions`.

## Choices where the spec was silent
- Overdue (Jethro's instruction): an unfinished task with a past date shows in Today, first, with a muted "from <short date>" tag, and its stored `dueDate` is unchanged until moved. Finished past tasks do not appear.
- "Later" column: a task dated after day 14 would otherwise vanish from the board, so a "Later" column appears only when such tasks exist (open a task to change its Day).
- "+" in each column header creates a task for that day (the spec had no create entry point besides Make task).
- "+ Label" in the modal creates a label inline, because desktop has no other way to create one until the Labels page. It reuses `addProject` and the mobile key format.
- The "Move to" list is a centred popover over the kanban pane rather than anchored to the card, so a scrolling column never clips it.
- Unscheduled completed tasks stay visible (struck through, last) per "completed tasks stay in their column". They will accumulate; a tidy-up rule can come later.
- Cards show the move icon only on hover, per the spec. Clicking the title or the checkbox works without hover.

## Limits

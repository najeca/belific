## Silent choices
- **Undo brings the dragged task back as a copy with a new id.** A tombstone wins every sync merge (checkpoint 5 rules, unchanged) and may already be on the server a second later, so un-tombstoning could never stick.
- **A dragged task's own subtasks are not carried onto the host** (only its title and done state become the subtask).
- **Tick on a task with subtasks ticks them all; unticking the task leaves them** (an assumption you approved).
- **Reminder leads need a start time.** Without one only Default and None apply and the note "Reminds at your daily reminder time" shows (approved).
- **Repeat is applied with an Apply button**, because Weekly with no day chosen is not a valid state and the summary line must be read first; closing the popover discards the draft. Every other dropdown applies on choice.
- **The Move to day "Moved to Mon 2 Nov" line was dropped** with the Kanban overlay.
- **The board no longer shows completed tasks unless "Show complete" is on** (this replaces the earlier handling); the left pane's "Done today" line is kept (label filter only).
- **Placed tasks hidden by the filter vanish from the Timebox too; events never do.**
- **Legacy phone items** are drawn as task rows and convert in place on their first edit (`lib/dumpConvert.ts`: concurrent edits share one conversion, a failed write keeps the item).
- **The iPhone's sync code is shared**, so it also probes the two new columns and round-trips subtasks and reminders once the migration is applied. No iPhone screen changed.
